# tools.txt — each tool's latest GitHub Release, fetched at image-build time
# by install-tools.sh. Format (pipe-separated): binary_name|owner/repo|asset_template
#
# Placeholders, substituted per build:
#   {TAG}         the release's raw tag_name, verbatim (e.g. "v10.5.0" or "15.2.0")
#   {VER}         {TAG} with any leading "v" stripped (e.g. "10.5.0")
#   {ARCH_GNU}    x86_64 / aarch64  (ripgrep, fd, bat, delta, eza)
#   {ARCH_SHORT}  amd64 / arm64    (gh, fzf)
#   {ARCH_MIXED}  x86_64 / arm64   (lazygit, gum, neovim)
#
# A project whose asset naming differs between architectures beyond these
# placeholders may supply an optional FOURTH field, used verbatim (after
# placeholder substitution) on arm64 in place of the third. rtk needs this:
# it ships a musl build for x86_64 but a gnu build for aarch64, so no single
# template covers both.
#
# Different upstream projects use different arch-naming and versioning
# conventions in their release asset filenames — verified against each
# project's actual latest release when this file was written; if a project
# changes its asset naming, install-tools.sh will fail loudly (404) rather
# than silently install the wrong thing.
#
# Tools with an official one-line multi-arch installer script (chezmoi,
# starship, uv, just, zoxide, ollama) are installed directly in the
# Dockerfile instead — no entry needed here.
